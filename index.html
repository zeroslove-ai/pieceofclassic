고전 한조각 Piece of Classic

고전 문학을 한 편씩 오디오 드라마와 그림으로 풀어 보는 YouTube 채널입니다. 첫 작품은 도스토옙스키의 『죄와 벌』입니다.

A YouTube channel that retells classic literature as illustrated audio drama, one piece at a time.

운영 도구 안내 / About our tool

채널 운영자는 자기 채널의 영상 업로드와 통계 확인을 위해 YouTube API 서비스를 쓰는 내부 도구를 사용합니다. 이 도구는 운영자 본인 채널에만 접근하며 일반 시청자의 정보는 다루지 않습니다.

The channel operator uses an internal tool built on YouTube API Services to upload videos and read statistics for the operator's own channels only.
