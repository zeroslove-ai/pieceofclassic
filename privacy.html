개인정보처리방침

시행일: 2026년 11월 12일

이 방침은 "고전 한조각" 채널 운영자가 쓰는 내부 운영 도구(이하 "도구")에 적용됩니다.

1. 누가 쓰는가

도구는 채널 운영자 본인만 씁니다. 외부 사용자에게 제공하지 않습니다.

2. 어떤 정보에 접근하는가

  • Google 계정 로그인(OAuth)으로 운영자 본인 YouTube 채널에 접근합니다.
  • 쓰는 기능: 운영자가 만든 영상 업로드와 정보 수정, 운영자 채널의 영상 목록·조회수·시청 지속률 같은 통계 읽기.
  • 시청자·구독자 등 다른 사람의 개인정보는 수집하지 않습니다.

3. 저장과 공유

  • 로그인 토큰과 통계는 운영자 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다.
  • 어떤 정보도 판매하거나 제3자와 공유하지 않습니다.

4. 접근 철회

Google 계정 권한 페이지에서 언제든 도구의 접근 권한을 해제할 수 있습니다.

5. YouTube API 서비스

도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
